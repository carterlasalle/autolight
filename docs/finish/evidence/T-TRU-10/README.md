# T-TRU-10: Security and license scanning

Closes spec 112 enforcement, F-QA-14 (CodeQL part).

## What changed

- `tools/license-check.mjs` (new): the license gate. Yarn dependencies come
  from `license-checker-rseidelsohn` (root devDep, hand-added entry for the
  orchestrator to install) with a `yarn licenses list` fallback; Python comes
  from `pip-licenses` run in a uv overlay
  (`uv run --project analysis --with pip-licenses pip-licenses --format=json`)
  so no pyproject line is needed yet; model weights and bundled binaries
  (FFmpeg, uv, Python, all-in-one-infer weights, beat-this weights) are a
  hand-maintained list pinned until T-OPS-05 bundles them.
- Denylist is GPL, AGPL, unlicensed, unknown; LGPL passes (FFmpeg and the
  OD-08 fpcalc binary are LGPL).
- `rkbx_link` is never a dependency: the checker scans every `package.json`
  manifest plus the installed yarn and pip environments for the name.
- Skip-BART/SeqLight tripwire (spec 112): the checker fails on any file,
  weight, or dataset from the unlicensed 2026 Skip-BART or SeqLight
  repositories. Docs prose may cite them as research; vendored files may not.
- CodeQL (CI): removed the `security-codeql` advanced-config job on
  2026-10-02. The repo has CodeQL default setup enabled (configured,
  js/ts plus python, extended suite), which rejects SARIF uploads from
  advanced-config runs. Default setup already scans every push, so the
  custom job was redundant. Security scanning is covered by default
  setup, not by a CI job in `ci.yml`.
- Root devDeps (hand-added entries): `license-checker-rseidelsohn` at
  `^5.0.1`.

## Proof

- `node tools/license-check.mjs --self-test`: OK, exit 0. The self-test is
  the failing-capable proof: it plants a `rkbx_link` manifest entry plus a
  `skip-bart-weights.safetensors` file in a temp dir and asserts the manifest
  scan and tripwire scan each catch exactly their plant, and it asserts
  GPL-3.0, GPL-2.0-only, AGPL-3.0, UNLICENSED, UNKNOWN, and empty are denied
  while MIT, ISC, LGPL-2.1-or-later, and "MIT OR Apache-2.0" pass.
- `THIRD_PARTY_NOTICES` (root, JSON): generated by the checker, hand list
  included. Remove the checker's plant-catching branch and the self-test goes
  red; add a GPL dependency and the `licenses` job goes red.
- Inspection reasoning (why a planted GPL dep is caught): every installed
  package license string is split on `; , | / ( )`, each token is tested
  against `/agpl/i`, `/\bgpl(?!l)/i`, `/^unlicensed$/`, `/^unknown$/`; a
  planted `GPL-2.0-only` token matches `\bgpl(?!l)` (the negative lookahead
  excludes only LGPL), so it fails the job by name.

## Delete test

Add a GPL dependency (or a `skip-bart-weights.safetensors` file, or a
`rkbx_link` dependency) and `node tools/license-check.mjs` exits 1 naming
the offender. The `licenses` CI job runs the same script and fails the same way.
